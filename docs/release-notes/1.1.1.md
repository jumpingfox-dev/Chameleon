# Chameleon 1.1.1 (build 3)

## Google Play "What's new" (en-US, under 500 characters)

```
Simpler sign-in: one Server field, with the port typed after a colon if it isn't 8096.
The field you're typing in stays above the keyboard.
The TV sidebar now dims with the page when a title is open.
Cleaner library links on the phone's Home screen.
Fixed captions overflowing Continue Watching and Next Up with larger text sizes.
Fixed a missing title in the Home carousel when its logo can't load.
```

If 1.1.0 (build 2) was never published, use 1.1.0's "What's new" text instead: it covers
the bigger changes, and this release's fixes are part of the same update for everyone.

## Full changes

**Sign-in**
- Host and Port are one Server field. An address without a port uses Jellyfin's 8096;
  one with `https://` is used as is, for reverse proxies.
- The field being typed in scrolls into view above the on-screen keyboard.
- Signing in without a server address or username explains what's missing, instead of
  showing the server's raw error.
- The Quick Connect dialog's text is centered.

**Fixes**
- The sidebar rail on TVs and wide screens dims along with the page while a title's details
  are open; selecting it closes them.
- Continue Watching and Next Up no longer overflow with a larger system font size.
- The Home carousel shows a title's name if its logo can't be loaded.
- Fixed the default port being added after a path in server addresses.

**Polish**
- The library links at the top of Home on phones are outlined like the Settings tabs, in a
  muted color, with their icons.
