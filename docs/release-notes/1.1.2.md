# Chameleon 1.1.2 (build 4)

## Google Play "What's new" (en-US, under 500 characters)

```
Fixed green edges around videos on some Android TVs.
```

## Full changes

**Playback**
- Fixed green bars at the edges of the picture on devices whose hardware decoder pads its
  frames (common on Android TV, seen with HEVC and Dolby Vision profile 8.1). Video now
  reaches the screen through a SurfaceTexture, which applies the decoder's crop; Flutter's
  default ImageReader route draws the padding too.

**Store listing**
- New TV screenshots for the details page and the Emerald theme.
